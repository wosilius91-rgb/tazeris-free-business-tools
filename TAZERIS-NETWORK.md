## Which destination should I use?

- Need a calculator, spreadsheet or seller tool → **Money Factory**.
- Need a ready Telegram utility → **Bot Factory**.
- Need a website fix, small custom Telegram bot or small Android app → **Service Storefront**.
- Need an agent-callable automation API → **App Factory public agent services**.

The network pages are intentionally linked to one another so discovery traffic can move to the most relevant TAZERIS service. Each service has its own scope and should not be assumed to provide capabilities listed only on another service.
